# Inflation verstehen

Statische Lernseite zur Gruppenpräsentation. Alle Quizantworten und Berechnungen bleiben im Browser. Keine Analysewerkzeuge oder Backend-Dienste.

## Starten

Die Datei `index.html` direkt öffnen oder diesen Ordner mit einem lokalen Webserver bereitstellen. Die Seite benötigt keine Build-Werkzeuge und keine externen JavaScript-Abhängigkeiten.

## GitHub Pages

Den Inhalt dieses Ordners in ein eigenes Repository `inflation-verstehen` übertragen. In **Settings > Pages** als Quelle **Deploy from a branch**, Branch **main**, Ordner **/(root)** wählen. Erst nach einem erfolgreichen Pages-Build die tatsächliche Adresse prüfen und den Präsentations-QR-Code erzeugen.

## Inhalte

`data.js` enthält sechs Themen, Quellen und die sechs Quizfragen. `app.js` steuert Kurzquiz, Zusatzquiz und Rechner. `style.css` enthält das responsive Design.
